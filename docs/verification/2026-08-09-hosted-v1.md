## Build-environment finding

`NEXT_PUBLIC_CETELE_DATA_ADAPTER` must be changed in the ignored `.env.local` before a clean Next.js build. A PowerShell-only process override produced a split build in which server output used the hosted adapter while the browser bundle retained the local adapter. The verified procedure is:

1. Stop the running Next.js process.
2. Set `NEXT_PUBLIC_CETELE_DATA_ADAPTER=supabase` in the ignored `.env.local`.
3. Remove `.next`.
4. Run `npm.cmd run build`, then start the application.
5. After hosted verification, restore `NEXT_PUBLIC_CETELE_DATA_ADAPTER=local`, remove `.next` again, and rebuild before local-adapter work.
